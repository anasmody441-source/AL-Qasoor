# 🚀 دليل الاستخدام السريع

## فتح الموقع

### الطريقة 1: مباشرة (بدون خادم)
```
افتح ملف index.html مباشرة في المتصفح
(اسحب وأفلت في نافذة المتصفح)
```

### الطريقة 2: مع خادم محلي

#### Python:
```bash
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

#### Node.js:
```bash
npx http-server
```

#### PHP:
```bash
php -S localhost:8000
```

## 🎯 تجربة الميزات

### 1. عرض المنتجات
- اضغط على أي منتج لعرض التفاصيل
- اختر الكمية
- اضغط "إضافة إلى السلة"

### 2. السلة
- اضغط على أيقونة السلة في الأعلى
- زيادة/تقليل الكميات
- حذف منتجات
- اضغط "Checkout" لإتمام الطلب

### 3. إتمام الطلب
- أدخل معلوماتك (الاسم، الهاتف، العنوان)
- راجع ملخص الطلب
- اضغط "تأكيد الطلب"
- سيظهر رقم الطلب

### 4. عرض الطلبات السابقة
- اضغط على الزر العائم (دائرة ذهبية) في أسفل يمين الشاشة
- شاهد جميع طلباتك المحفوظة
- كل طلب يحتوي على: رقم الطلب، التاريخ، المنتجات، المجموع

### 5. تبديل اللغة
- اضغط على أيقونة الكرة الأرضية في الأعلى
- يتحول الموقع بين العربية والإنجليزية
- يتغير اتجاه النص تلقائياً (RTL/LTR)

## 📱 اختبار الاستجابة (Responsive)

### طريقة 1: Chrome DevTools
1. اضغط `F12`
2. اضغط `Ctrl+Shift+M` (أو أيقونة الموبايل)
3. جرب أحجام مختلفة:
   - iPhone SE (375px)
   - iPad (768px)
   - Desktop (1920px)

### طريقة 2: تغيير حجم النافذة
اسحب نافذة المتصفح وشاهد كيف يتكيف التصميم

## 💾 إدارة البيانات (localStorage)

### عرض البيانات المحفوظة:
افتح Console (F12) واكتب:

```javascript
// عرض السلة
console.log(JSON.parse(localStorage.getItem('cart')));

// عرض الطلبات
console.log(JSON.parse(localStorage.getItem('orders')));
```

### حذف البيانات (للتجربة):
```javascript
// حذف السلة
localStorage.removeItem('cart');

// حذف الطلبات
localStorage.removeItem('orders');

// حذف كل شيء
localStorage.clear();

// ثم أعد تحميل الصفحة
location.reload();
```

## 🎨 التخصيص السريع

### تغيير اللون الذهبي:
افتح `styles.css` واستبدل:
```css
--golden: #c9a961;  /* لون جديد */
```

### إضافة منتج جديد:
افتح `script.js` وأضف في `menuItems`:
```javascript
{
    id: '9',
    name: 'اسم المنتج',
    nameAr: 'الاسم بالعربية',
    description: 'الوصف',
    descriptionAr: 'الوصف بالعربية',
    price: 20.00,
    category: 'broasted',
    image: 'رابط الصورة',
    popular: false
}
```

### تغيير معلومات التواصل:
افتح `index.html` وابحث عن:
- `+966 12 345 6789` (رقم الهاتف)
- `Al-Qasoor District` (العنوان)

## 🐛 حل المشاكل

### الموقع لا يفتح:
- تأكد من فتح `index.html` وليس ملف آخر
- جرب متصفح آخر (Chrome, Firefox, Safari)

### الصور لا تظهر:
- تحتاج لاتصال بالإنترنت (الصور من Unsplash/Pexels)
- إذا لا يوجد إنترنت، استبدل روابط الصور بصور محلية

### localStorage لا يعمل:
- تأكد من أن المتصفح يدعم localStorage
- جرب في وضع التصفح العادي (ليس الخاص/Incognito)

### التصميم معطل:
- تأكد من وجود ملف `styles.css` في نفس المجلد
- افتح Console (F12) وتأكد من عدم وجود أخطاء
