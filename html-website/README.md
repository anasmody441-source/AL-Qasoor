# موقع مطعم بروستد القصور 🍗

موقع إلكتروني احترافي لمطعم بروستد القصور بتصميم أنيق وعصري

## 📁 محتويات المشروع

```
html-website/
├── index.html          # الصفحة الرئيسية
├── styles.css          # ملف التصميم
├── script.js           # ملف البرمجة والوظائف
└── README.md           # هذا الملف
```

## ✨ المميزات

### 🎨 التصميم
- تصميم أنيق باستخدام ألوان دافئة (ذهبي، فحمي، كريمي)
- متجاوب تماماً مع جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- تأثيرات حركية سلسة عند التفاعل
- صور احترافية للأطباق

### 🌐 اللغات
- دعم كامل للغتين العربية والإنجليزية
- تبديل سهل بين اللغات بضغطة زر واحدة
- اتجاه النص RTL للعربية و LTR للإنجليزية

### 📱 الأقسام
1. **القسم البطولي (Hero)**: عنوان جذاب مع تقييم المطعم
2. **من نحن**: معلومات عن المطعم والمميزات
3. **القائمة**: عرض الأطباق مع إمكانية الفلترة حسب الفئة
4. **التقييمات**: آراء العملاء السابقين
5. **المعرض**: صور الأطباق والمطعم
6. **اتصل بنا**: نموذج تواصل وخريطة الموقع

### 🛒 سلة التسوق
- إضافة وحذف الأطباق
- تعديل الكميات
- حفظ السلة في المتصفح (localStorage)
- حساب المجموع تلقائياً

### 🔔 الإشعارات
- إشعارات جميلة عند إضافة المنتجات
- رسائل نجاح عند إرسال النماذج

## 🚀 كيفية الاستخدام

### طريقة بسيطة (بدون خادم):
1. افتح ملف `index.html` مباشرة في متصفحك
2. الموقع سيعمل مباشرة!

### طريقة احترافية (مع خادم محلي):

#### باستخدام Python:
```bash
# إذا كان لديك Python 3
python -m http.server 8000

# ثم افتح المتصفح على
# http://localhost:8000
```

#### باستخدام Node.js:
```bash
# تثبيت http-server
npm install -g http-server

# تشغيل الخادم
http-server

# افتح المتصفح على العنوان الذي يظهر
```

#### باستخدام VS Code:
- ثبت إضافة "Live Server"
- انقر بزر الماوس الأيمن على `index.html`
- اختر "Open with Live Server"

## 📦 الرفع على الإنترنت

يمكنك رفع الموقع على أي استضافة تدعم HTML الثابت:

### GitHub Pages (مجاناً):
1. أنشئ مستودع (repository) جديد
2. ارفع الملفات
3. اذهب إلى Settings > Pages
4. اختر Branch: main
5. احفظ، وسيكون موقعك جاهزاً!

### Netlify (مجاناً):
1. اذهب إلى netlify.com
2. اسحب مجلد المشروع إلى الصفحة
3. موقعك جاهز مباشرة!

### Vercel (مجاناً):
1. اذهب إلى vercel.com
2. قم بتوصيل GitHub أو ارفع الملفات مباشرة
3. موقعك جاهز!

## 🎯 التخصيص

### تغيير الألوان:
افتح `styles.css` وعدّل المتغيرات في البداية:
```css
:root {
    --charcoal: #1a1a1b;      /* لون الخلفية الداكن */
    --golden: #c9a961;         /* اللون الذهبي */
    --cream: #f5f5f0;          /* لون النص الفاتح */
}
```

### تغيير محتوى القائمة:
افتح `script.js` وعدّل مصفوفة `menuItems`:
```javascript
const menuItems = [
    {
        id: '1',
        name: 'اسم الطبق بالإنجليزية',
        nameAr: 'اسم الطبق بالعربية',
        description: 'الوصف بالإنجليزية',
        descriptionAr: 'الوصف بالعربية',
        price: 25.00,
        category: 'broasted', // أو 'roasted' أو 'appetizers'
        image: 'رابط الصورة',
        popular: true // أو false
    }
];
```

### تغيير معلومات التواصل:
افتح `index.html` وابحث عن قسم Contact لتعديل:
- رقم الهاتف
- العنوان
- رابط خريطة Google Maps

### إضافة صور للمعرض:
افتح `script.js` وعدّل مصفوفة `galleryImages`:
```javascript
const galleryImages = [
    'رابط الصورة 1',
    'رابط الصورة 2',
    'رابط الصورة 3'
];
```
