# موقع مطعم بروستد القصور 🍗

موقع إلكتروني احترافي لمطعم بروستد القصور بتصميم أنيق وعصري

## 📁 محتويات المشروع

```
html-website/
├── index.html          # الصفحة الرئيسية
├── styles.css          # ملف التصميم
├── script.js           # ملف البرمجة والوظائف
└── README.md           # هذا الملف
```

## ✨ المميزات

### 🎨 التصميم
- تصميم أنيق باستخدام ألوان دافئة (ذهبي، فحمي، كريمي)
- متجاوب تماماً مع جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- تأثيرات حركية سلسة عند التفاعل
- صور احترافية للأطباق

### 🌐 اللغات
- دعم كامل للغتين العربية والإنجليزية
- تبديل سهل بين اللغات بضغطة زر واحدة
- اتجاه النص RTL للعربية و LTR للإنجليزية

### 📱 الأقسام
1. **القسم البطولي (Hero)**: عنوان جذاب مع تقييم المطعم
2. **من نحن**: معلومات عن المطعم والمميزات
3. **القائمة**: عرض الأطباق مع إمكانية الفلترة حسب الفئة
4. **التقييمات**: آراء العملاء السابقين
5. **المعرض**: صور الأطباق والمطعم
6. **اتصل بنا**: نموذج تواصل وخريطة الموقع

### 🛒 نظام الطلبات المتقدم
- **عرض تفاصيل المنتج**: اضغط على أي منتج لعرض التفاصيل الكاملة
- **إضافة للسلة**: اختر الكمية وأضف للسلة
- **تعديل السلة**: زيادة/تقليل الكميات أو حذف المنتجات
- **إتمام الطلب**: نموذج متكامل لإدخال معلومات العميل
- **ملخص الطلب**: عرض جميع المنتجات والمجموع الكلي
- **حفظ الطلبات**: جميع الطلبات تُحفظ في localStorage
- **عرض الطلبات السابقة**: زر عائم لعرض جميع طلباتك
- **رقم طلب فريد**: كل طلب يحصل على رقم تتبع خاص
- **تاريخ ووقت الطلب**: تسجيل تلقائي لوقت الطلب

### 📱 متجاوب 100%
الموقع متجاوب تماماً مع جميع أحجام الشاشات:
- **هواتف صغيرة** (320px - 374px): تصميم مضغوط ومناسب
- **هواتف عادية** (375px - 767px): واجهة مثالية للموبايل
- **تابلت** (768px - 1023px): عرض متوازن بعمودين
- **كمبيوتر محمول** (1024px - 1439px): تصميم كامل بأعمدة متعددة
- **شاشات كبيرة** (1440px+): استغلال كامل للمساحة

### 🔔 الإشعارات
- إشعارات جميلة عند إضافة المنتجات
- رسائل نجاح عند إرسال النماذج
- تأكيد عند إتمام الطلب

## 🚀 كيفية الاستخدام

### طريقة بسيطة (بدون خادم):
1. افتح ملف `index.html` مباشرة في متصفحك
2. الموقع سيعمل مباشرة!

### طريقة احترافية (مع خادم محلي):

#### باستخدام Python:
```bash
# إذا كان لديك Python 3
python -m http.server 8000

# ثم افتح المتصفح على
# http://localhost:8000
```

#### باستخدام Node.js:
```bash
# تثبيت http-server
npm install -g http-server

# تشغيل الخادم
http-server

# افتح المتصفح على العنوان الذي يظهر
```

#### باستخدام VS Code:
- ثبت إضافة "Live Server"
- انقر بزر الماوس الأيمن على `index.html`
- اختر "Open with Live Server"

## 🎯 التخصيص

### إدارة الطلبات:
جميع الطلبات محفوظة في `localStorage` تحت مفتاح `orders`. كل طلب يحتوي على:
```javascript
{
    id: 'ORD-1234567890',
    orderNumber: '#ABC123',
    customer: {
        name: 'اسم العميل',
        phone: '+966 XXX XXX XXX',
        address: 'العنوان الكامل'
    },
    items: [
        {
            id: '1',
            name: 'اسم المنتج',
            quantity: 2,
            price: 25.00,
            total: 50.00
        }
    ],
    total: 50.00,
    status: 'pending',
    date: '2025-02-05T...',
    dateFormatted: 'التاريخ المنسق'
}
```

### عرض الطلبات:
- اضغط على الزر العائم (FAB) في أسفل الشاشة
- أو افتح console واكتب:
```javascript
// عرض جميع الطلبات
console.log(JSON.parse(localStorage.getItem('orders')));

// حذف جميع الطلبات (للتجربة)
localStorage.removeItem('orders');
```

### تغيير الألوان:
افتح `styles.css` وعدّل المتغيرات في البداية:
```css
:root {
    --charcoal: #1a1a1b;      /* لون الخلفية الداكن */
    --golden: #c9a961;         /* اللون الذهبي */
    --cream: #f5f5f0;          /* لون النص الفاتح */
}
```

### تغيير محتوى القائمة:
افتح `script.js` وعدّل مصفوفة `menuItems`:
```javascript
const menuItems = [
    {
        id: '1',
        name: 'اسم الطبق بالإنجليزية',
        nameAr: 'اسم الطبق بالعربية',
        description: 'الوصف بالإنجليزية',
        descriptionAr: 'الوصف بالعربية',
        price: 25.00,
        category: 'broasted', // أو 'roasted' أو 'appetizers'
        image: 'رابط الصورة',
        popular: true // أو false
    }
];
```

### تغيير معلومات التواصل:
افتح `index.html` وابحث عن قسم Contact لتعديل:
- رقم الهاتف
- العنوان
- رابط خريطة Google Maps

### إضافة صور للمعرض:
افتح `script.js` وعدّل مصفوفة `galleryImages`:
```javascript
const galleryImages = [
    'رابط الصورة 1',
    'رابط الصورة 2',
    'رابط الصورة 3'
];
```
